# 📂 Dados

Os dados utilizados neste projeto são provenientes da competição **House Prices - Advanced Regression Techniques**, do Kaggle.

## Conjuntos utilizados

### `train.csv`

Conjunto utilizado para desenvolvimento e treinamento dos modelos.

- **1.460 imóveis**
- Contém as características dos imóveis.
- Contém a variável `SalePrice`, que representa o preço de venda.

### `test.csv`

Conjunto utilizado para geração das previsões finais.

- **1.459 imóveis**
- Contém as características dos imóveis.
- Não possui a variável `SalePrice`, pois esse é o valor que deve ser previsto pelo modelo.

## Variável alvo

A variável utilizada como alvo do projeto é:

`SalePrice`

Ela representa o preço de venda de cada imóvel.

## Observação

Os arquivos `train.csv` e `test.csv` não foram armazenados neste repositório.

Eles podem ser obtidos diretamente na competição **House Prices - Advanced Regression Techniques**, disponível no Kaggle.
